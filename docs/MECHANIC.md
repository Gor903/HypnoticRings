# Механика — указатель

План (§0.17, §5 фаза 0) просит файл `docs/MECHANIC.md` с уточнёнными числами
механики. Он есть, но содержимого в нём нет намеренно.

**Механика с числами живёт в одном месте — `CONTRACT.md` §2.** Вторая копия
тех же формул разошлась бы с первой на первой же правке баланса, а правила
проекта (`docs/README.md`) запрещают держать два источника одного факта.

| Что искали | Где это |
|---|---|
| единицы, гравитация, система координат | `CONTRACT.md` §2.1 |
| устройство кольца, `θ = w/R`, `w_min`, коллайдеры | `CONTRACT.md` §2.2 |
| шарик, материалы, шаг физики, ограничение скорости | `CONTRACT.md` §2.3 |
| геометрия тоннеля, начальная расстановка колец | `CONTRACT.md` §2.4 |
| закон сжатия, втягивание, исчезновение и спавн колец | `CONTRACT.md` §2.5 |
| условие прохождения кольца | `CONTRACT.md` §2.6 |
| кривая сложности | `CONTRACT.md` §2.7 |
| гарантия проходимости | `CONTRACT.md` §2.8 |
| счёт, рекорд, открытие тем | `CONTRACT.md` §2.9 |
| управление и его параметры | `CONTRACT.md` §2.10 |
| что принципиально не помещается в `HR.Core` | `CONTRACT.md` §2.11 |
| условия поражения | `CONTRACT.md` §1 |

Числа, попавшие в код, берутся не отсюда и не из `CONTRACT.md`, а из ассетов
`GameConfig` / `DifficultyCurve` / `ThemeData`. Контракт — то, чему эти
ассеты обязаны соответствовать, и то, что проверяют тесты.
