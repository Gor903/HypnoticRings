# Прогресс

Чек-лист всех фаз. Обновляется после каждой завершённой задачи. Фаза
закрывается только когда отмечены **все её гейты** — отметка ставится по
доказательству (вывод теста, отчёт, лог), а не по ощущению.

Обозначения: `[ ]` не начато · `[~]` в работе · `[x]` сделано и доказано.

**Текущая фаза: 6.** Фазы 0–5 закрыты 27 октября 2026, все гейты с доказательствами.

### Слайс 8 — замер окна игрока

### Слайсы 9–10 — режим хардкор целиком

- [x] Правило второго касания живёт в `GameManager`, а не в тоннеле: тоннель
      считает касания в любом режиме (обычной игре они нужны для звука), а что
      счёт **значит** — это правило
- [x] «Горячее» кольцо: при израсходованной попытке подмешивается цвет
      красного круга на 70%. Предупреждение приходит на касании, которое тратит
      попытку, а не на том, которое убивает
- [x] Хардкорная таблица — функция, а не второй ассет: её строки не вариация
      обычных (сжатия нет вовсе), и ассет приглашал бы настроить одну и забыть
      другую. Углы 129/118/101/84/66
- [x] `GameMode` в ядре; кривая выбирается один раз на забег
- [x] Рекорд хардкора хранится отдельно; кнопка в меню гаснет до рекорда 30 и
      **говорит почему**, а не прячется
- [x] Retry сохраняет режим: проигравший хардкор хочет ещё хардкор
- [x] **Замер обеих конфигураций:** широкие отверстия делают типичное кольцо
      вдвое легче (29 против 49 °/с) и **не трогают хвост** (8.6% против 8.5%).
      Хвост — свойство полёта шарика, а не ширины выреза (D-071)
- [x] Утверждение теста переписано под измеренное, а не под цель плана
- [x] **Гейт:** EditMode 282/282, PlayMode 48/48
