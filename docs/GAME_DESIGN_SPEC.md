# GAME_DESIGN_SPEC.md — указатель

Спецификация лежит в **[`design/GAME_DESIGN_SPEC.md`](design/GAME_DESIGN_SPEC.md)**,
в неизменённом виде. Спецификация §15.1 просит положить её в
`docs/GAME_DESIGN_SPEC.md` — путь занят этим указателем, чтобы копии не было
и расходиться было нечему.

Приоритет при конфликте не меняется: `design/GAME_DESIGN_SPEC.md` старше
`design/CLAUDE_CODE_PLAN.md`.

Рабочее прочтение спецификации — `CONTRACT.md`: там те же числа, плюс
решения по всему, о чём спецификация умолчала, и явно отмеченные места, где
спецификация и план противоречили друг другу.
